# Changelog

## 0.2.0 — 2026-10-07

Planned public release following the initial 0.1.0 development series.

- Add the agent-defined `kev_custom_decision` advisory tool while retaining the
  focused decision tools.
- Add CPU-only Gutsy deployment support and preserve rejection and abstention
  semantics in advisory responses.
- Add synthetic MCP smoke verification and paired Project23 evaluation tooling.
- Make examples and integration defaults portable across hosts; network
  deployments must explicitly configure their allowed hosts and credentials.
- Clarify that model probabilities are uncalibrated for a user's workload and
  that the project does not execute trades.

This release does not claim validated trading performance or calibrated
probabilities.
